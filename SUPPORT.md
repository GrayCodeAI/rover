# Support and publication status

This source bundle is an experimental implementation. No public service, package-manager
listing, support SLA, hosted issue queue, or release signing identity was created. Use
README and `rover help` for the implemented command surface. Include platform, toolchain,
exact command, and sanitized evidence when reporting a problem to the chosen maintainer.

Do not infer `go install github.com/GrayCodeAI/rover/...@latest` availability from the
module path. GitHub publication is a separate step in the owner's chosen repository.
