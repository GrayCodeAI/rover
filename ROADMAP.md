# Roadmap and completion gates

The ten-layer master plan remains the destination. The alpha's source is a usable
implementation across these responsibilities, not a claim of full product completion.

## Delivered in 0.0.1

Local CLI/TUI and PTY sessions; native CLI profiles with fixture tests; worktree tasks,
bounded repair; dependency scheduling and verified source integration; context/notes;
scoped MCP and remote CLI; structured verification/counterfactual/mutation; evidence,
backup/signatures; offline check-order experiments with explicit promotion.

## Required before a production claim

1. Supported-current toolchain and target-OS matrix, live provider compatibility.
2. Live restricted-executor tests and independent protected CI publisher.
3. Real credential brokerage and organization identity/separate authority roles.
4. Recovery/fencing tests on actual remote worker hosts, global resource accounting.
5. Schedules/webhooks and external delivery operations with reconciliation.
6. Domain verifier packs with actual tools, realistic fixtures and documented limits.
7. Repository/context connectors with authorization and evaluation.
8. Release signing/update trust, retention/deletion, complete backup/recovery SLOs.
9. Evaluation against existing workflows using the same agents/tools; no unmeasured
   claim that parallelism, more checks, learning or RL makes development better.

Full learning-model training, self-play/RSI, web/mobile clients and universal provider
support are not implemented. Do not rename those omissions as supported features.
